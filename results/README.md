# Board results

Per-inference CSVs written by the board test scripts (GateMate CCGM1A1, 10 MHz board clock).
Each row is one input sent over UART: board output, reference output and the cycle count
measured by the hardware counter.

| File | Design | Test | Reference | Thesis |
|---|---|---|---|---|
| `trained_board_results.csv` | MyNet CNN, float32 (SODA flow), trained on MNIST 0–4 vs 5–9 | first 500 MNIST test images (`gatemate_inference.py --dataset`) | PyTorch float32 | Table 3.3 |
| `jet_board_rf_M1.csv` | Jet tagger, `ap_fixed<16,6>`, 1 multiplier (v3) | first 1,000 test jets (`jet_inference.py`) | hls4ml bit-accurate emulation | Table 4.4 |
| `jet_board_rf_M16.csv` | Jet tagger, `ap_fixed<16,6>`, 16 multipliers (v3) | first 1,000 test jets (`jet_inference.py`) | hls4ml bit-accurate emulation | Table 4.4 |
| `jet_board_M2.csv` | Jet tagger, `ap_fixed<16,6>`, 2 multipliers (v1 layout, one memory per lane) | first 1,000 test jets (`jet_inference.py`) | hls4ml bit-accurate emulation | Table 4.4 |
| `jetf_board.csv` | Jet tagger, float32 (SODA flow) | first 1,000 test jets (`jetf_inference.py`) | PyTorch float32 | Table 4.3 |

Summary: MyNet 95.0% (500/500 same class as PyTorch); fixed-point jet tagger 78.0%,
1000/1000 bit-exact for every tested design; float32 jet tagger 77.7% (1000/1000 same class).

Not included: the 12-input board test of the untrained MyNet (results reported in the thesis,
Section 3.5.3, no CSV was saved) and the nextpnr utilisation reports (regenerated by
`build_board.sh` in `output/board_<tag>/`).
